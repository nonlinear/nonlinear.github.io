Librarian is a semantic search engine for personal book collections. Uses FAISS for vector similarity search and a custom NLP pipeline for multi-language understanding.

**Key capabilities:**
- Semantic search across 1000+ books
- Multi-language support (EN, PT, FR)
- FAISS vector indexing
- Local NLP pipeline (no external API calls)

Read more at the [Librarian site](https://nonlinear.nyc/personal/projects/librarian).
