  • Envelope Authoritative ClassificationP09E102 — Stop classifying control-plane events by matching text inside the message body. Classify only by an authoritative marker: a declared type field on the envelope, or (interim) an ANCHORED match on the transport envelope. Body-substring matching is banned. Fixes two opposite defects at once.
  • Collapse by MetadataP09E103 — Heartbeats (and other control-plane events) are shown, not hidden — but as a SINGLE collapsed pill (e.g. "50 ❤️"), not one bubble per event and not zero. Classification is driven by an authoritative TYPE field (metadata), never by matching substrings of the message body — so there are no false positives when a normal message merely mentions a token.

  • Provenance stampingP09E107 — Every message carries an immutable, self-describing provenance stamp written ONCE at generation time by the layer that actually knows the fact. Display is a projection of the stamp; readers never guess, never backfill, never invent empty fields.

In the same way that a well-designed object reveals how it wants to be held, this product reveals how it wants to be used before anyone reads a word. That is the whole ambition: cognition that shows itself in the surface.

What it is

It began as an internal instrument and stayed one. The shape came from use, not from specification — every part that survived is a part someone reached for more than once. What follows is a description of that shape.

How it works

Three movements, in order. First the intake, where material arrives unformed. Then the reduction, where it is made small enough to hold. Finally the return, where it goes back out into the same world that produced it.
