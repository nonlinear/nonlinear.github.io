Mood

Image curation and visual reference. Board by feel, not by folder.

Currently workingActive epics

  • Reels IndexP13E004 — A personal visual index of referenced media, searchable and navigable by tag. A source adapter is the only thing a new host requires, and Instagram is the first one. The video is not stored: the reference, its metadata and its tags point back to the host.
  • Art StudyP13E008 — The agent covers art learning, starting with charcoal and widening to materials, techniques and drawing or painting schools in the city. Each entry is a study item with a source, not a bookmark.
  • Tool AuditP13E009 — Every MCP and skill available to the agent is audited, its access is documented, and the blockers are resolved or named. Missing tools are written down with what they would enable.

Coming soonPlanning epics

  • Collection EngineP13E001 — One engine serves visual collections. A path selects a collection and a viewer, the root path is the public default, and other paths exist without being advertised. Functional capacity grows without multiplying the operational surface.
  • Hidden ViewerP13E002 — A references path exists as an alternate viewer: one image at a time, chosen at random, changing every thirty minutes. No link and no readme point at it. Whoever knows the path knows it.
  • Charcoal SourcesP13E003 — Reference books on charcoal drawing are collected and organized, with the ones already in the library kept where they are and the missing ones acquired. The set is complete enough to study from without searching again.
  • Reels ScrapingP13E005 — A scheduled scrape detects newly saved reels and injects them into the index, so a save becomes a searchable reference without a manual pass. The source adapter for a second host is planned on the same contract.
  • Reels DesignP13E006 — The visual layer of the reels index is defined and built: the grid with tag search, the thumbnail, and the modal that shows the media. The technical path is closed and versioned elsewhere; this epic holds only the work that comes after it.
  • Hashtag VocabularyP13E010 — A vocabulary layer enriches the raw tags of any source with concepts, aliases and translations, at the same level as a source adapter and not as a cleaner after the fact. The layer is planned and SKOS-aligned; it does not act yet.
  • Traffic CapP13E015 — When traffic exceeds capacity the service degrades on purpose instead of failing: requests are rate limited at the proxy and the CDN, and a busy page stands in for the collection. The cap is a number the operator sets, not an outage.
  • Immich ConversionP13E016 — The library conversion is decided from measured numbers on the real collection, not from a readme estimate: whether to convert originals to newer formats, at what saving, and what breaks. The answer is a decision with evidence attached.

In the same way that a well-designed object reveals how it wants to be held, this product reveals how it wants to be used before anyone reads a word. That is the whole ambition: cognition that shows itself in the surface.

What it is

It began as an internal instrument and stayed one. The shape came from use, not from specification — every part that survived is a part someone reached for more than once. What follows is a description of that shape.

How it works

Three movements, in order. First the intake, where material arrives unformed. Then the reduction, where it is made small enough to hold. Finally the return, where it goes back out into the same world that produced it.

flowchart LR
  A[intake] --> B[reduction]
  B --> C{holds?}
  C -->|yes| D[return]
  C -->|no| B

Status

Working, with the usual caveats. Nothing here asks for attention it has not earned, and nothing claims to be finished.
